# Experiment index

## Experiment 001 — End-to-end baseline

Controlled Level 1 `slugify` repair using local Aider, an SSH tunnel, remote vLLM, Qwen2.5-Coder-7B-Instruct, and an RTX A5000. Result: partial, with 3/5 tests passing after three inference turns.

## Experiment 002 — Free-form human interaction

Direct chat plus a Space Invaders-style game request. Result: inference felt fast, but conversation and coding quality were not practically useful to the user. This is a qualitative exploration rather than a reproducible benchmark.
